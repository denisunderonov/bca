## О проекте

**Организация:** кафе с системой анализа использования ингредиентов в блюдах.

**Предметная область:** оптимизация использования ингредиентов в ресторанном бизнесе, включая учёт, анализ и прогнозирование их расходования.

**Проблемная область:**

- ручной учёт ингредиентов приводит к ошибкам и перерасходу продуктов;
- отсутствует система анализа популярности блюд и их влияния на расход ингредиентов;
- сложности в планировании закупок из-за недостатка данных.

**Идея проекта:** создать информационную систему, которая автоматически списывает ингредиенты по рецептам, формирует аналитические отчёты, прогнозирует потребность в закупках и интегрируется с POS/кассовым ПО.

---

## Цели и задачи

### Цели организации

- Снижение затрат на ингредиенты за счёт точного учёта и минимизации отходов.
- Оптимизация меню на основе анализа востребованности блюд.
- Улучшение планирования закупок продуктов.

### Задачи организации

- Внедрение системы автоматического списания ингредиентов при приготовлении блюд.
- Разработка отчётов для анализа расхода продуктов.
- Интеграция данных о заказах с системой учёта ингредиентов.

### Цели проектирования

- Создание системы для отслеживания использования ингредиентов в режиме реального времени.
- Автоматизация формирования отчётов для анализа и принятия решений.

### Задачи проектирования

- Разработка базы данных рецептов с указанием норм ингредиентов на каждое блюдо.
- Интеграция системы учёта с кассовым ПО для автоматического списания продуктов.
- Создание дашбордов для визуализации данных:
  - топ популярных блюд;
  - динамика расхода ингредиентов;
  - прогноз потребности в закупках.

---

## Основные бизнес-процессы

- **Приём и обработка заказов:** заказы через официантов, мобильное приложение или терминалы самообслуживания; фиксация блюд в цифровом формате.
- **Приготовление блюд:** ручное приготовление по стандартным рецептам; учёт ингредиентов, используемых в каждом заказе.
- **Учёт и анализ ингредиентов:** автоматическое списание ингредиентов из базы данных; формирование отчётов о расходе продуктов.
- **Планирование закупок:** прогнозирование потребности в ингредиентах на основе исторических данных.

---

## AS-IS / TO-BE

| Процесс | AS-IS | TO-BE |
|---|---|---|
| Учёт ингредиентов | Повара вручную записывают продукты в журнал; менеджеры еженедельно сводят данные в Excel | Система автоматически списывает ингредиенты по рецепту; данные обновляются в реальном времени |
| Формирование отчётов | Ручной сбор данных, отчёты в Excel | Ежедневные отчёты о расходе; анализ связи популярности блюд и затрат |
| Планирование закупок | Субъективные оценки, риск избытка или дефицита | Рекомендации по закупкам на основе прогноза спроса и текущих остатков |
| Обслуживание клиента | Бумажные бланки, устный заказ, ручная передача на кухню | Электронные заказы, POS-система, KDS, AI-прогнозирование |

**Развитие после внедрения:**

- мобильное приложение для поваров с мгновенными корректировками рецептов;
- интеграция с поставщиками для автоматических заказов;
- анализ сезонности спроса для оптимизации меню.

**Основные классы:**

- `Client` — клиент, предпочтения, заказы;

- `OrderItem` — позиция заказа;

- `ReportGenerator` — отчёты;
- `Report` — хранение отчёта.

## Сбалансированная система показателей

![ССП](images/bsc-lr3.png)

![Визуальное представление ССП](images/bsc-visual-lr3.png)

### Финансы

- **Цель:** повышение рентабельности и снижение затрат.
- **Стратегическая цель:** рост прибыли.
- **Ключевой показатель:** маржа прибыли.
- **Инициатива:** оптимизация расходов на закупку и использование ресурсов.

### Клиенты

- **Цель:** повышение удовлетворённости клиентов.
- **Стратегическая цель:** улучшение клиентского опыта.
- **Ключевой показатель:** NPS.
- **Инициатива:** гарантия наличия всех блюд в меню.

### Внутренние бизнес-процессы

- **Цели:** автоматизация учёта ингредиентов, повышение точности списания, оптимизация закупок и меню.
- **Стратегическая цель:** повышение эффективности внутренних процессов.
- **Ключевой показатель:** процент снижения потерь ингредиентов.
- **Инициатива:** внедрение системы учёта и прогнозирования остатков.

### Обучение и рост

- **Цель:** повышение квалификации персонала.
- **Стратегическая цель:** развитие компетентности сотрудников.
- **Ключевой показатель:** доля обученного персонала.
- **Инициатива:** регулярные тренинги по работе с системами учёта и аналитики.

## Результаты проекта

- Автоматическое списание ингредиентов по рецептам устраняет до 95% ошибок учёта.
- Прогнозирование закупок на основе AI-аналитики снижает риски нехватки ресурсов.
- Внедрение ССП определяет KPI по финансам, клиентам, процессам и обучению.
- Система обеспечивает прозрачность, контроль и постоянное улучшение процессов.
- Перспективы: облачная синхронизация для сетевых кафе, IoT-датчики для контроля сроков годности, интеграция с государственными системами.
